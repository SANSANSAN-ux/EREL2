# ЭРЭЛ

Минимальная рабочая версия школьной платформы на FastAPI.

## Файлы
Все файлы находятся в корне репозитория: `main.py`, `database.py`, `models.py`, `security.py`, `index.html`, `style.css`, `app.js`.

## Render
- Runtime: Python 3
- Build Command: `pip install -r requirements.txt`
- Start Command: `uvicorn main:app --host 0.0.0.0 --port $PORT`

Добавьте переменные окружения:
- `SECRET_KEY` — длинная случайная секретная строка.
- `DATABASE_URL` — адрес PostgreSQL Render (если используете PostgreSQL).
- `COOKIE_SECURE=true`

Если `DATABASE_URL` не задан, используется SQLite. На Render локальная SQLite-база может сбрасываться при пересоздании сервиса; для постоянных данных подключите PostgreSQL.

## Первый аккаунт
Первый зарегистрированный пользователь автоматически получает роль администратора. Все следующие получают роль участника. Не публикуйте ссылку на регистрацию до согласования правил доступа.

## Важно
Это стартовая версия для тестирования, а не сертифицированная школьная система. Перед реальным использованием настройте резервное копирование, ограничения доступа, модерацию и политику обработки персональных данных. Не загружайте реальные данные учеников без разрешения школы и ответственных взрослых.
